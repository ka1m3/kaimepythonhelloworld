# kaimepythonhelloworld

Простой Telegram-бот на Python для демонстрации работы с Git.

## Возможности

- Приветствие и меню кнопок
- Игра «Угадай число»
- Команды /start, /help, /game

## Установка

1. Установить зависимости: pip install -r requirements.txt
2. Получить токен у @BotFather в Telegram.
3. Вставить токен в bot.py в переменную BOT_TOKEN.
4. Запустить: python bot.py
